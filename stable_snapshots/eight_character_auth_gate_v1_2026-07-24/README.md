# 八角色身份门槛稳定快照

创建日期：2026-07-24

本快照固定“身份入口 → 游客或手机号用户 → 八角色首页 → 实时通话”的本地产品原型。

## 固定入口

- 身份入口：`http://127.0.0.1:8765/ui_prototypes/yuhuang_mobile_v1/index.html`
- 八角色首页：`http://127.0.0.1:8765/ui_prototypes/yuhuang_mobile_v1/home.html`
- Realtime Relay：`http://127.0.0.1:3001/`

## 功能边界

- 本地演示验证码固定为 `123456`，不会发送真实短信。
- 仅保存经过严格校验的身份状态；手机号用户只保存脱敏手机号。
- 游客可以浏览、滑动切换八角色并进入语音通话，但不能打开或确认充值。
- 角色切换只保留左右滑动，不包含角色选择按钮、列表或卡片。
- VIP 文案由有效身份状态派生，仅用于原型展示，不代表真实付费会员状态。
- 充值、微信和支付宝均为本地界面演示，不会产生真实扣款。
- 真实上线必须由服务端完成验证码签发、频率限制、验证、会话管理和支付鉴权。

## 启动

在项目根目录运行：

```bash
./start_full_demo.sh
```

脚本会先检查 `127.0.0.1:3001` 和 `127.0.0.1:8765`，端口冲突时立即退出。
